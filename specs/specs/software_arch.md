# Программная архитектура веб-приложения "Night City Guide & Build Planner"

Для реализации интерактивного гида по Cyberpunk 2077 выбрана классическая трехзвенная архитектура (Client-Server-Database) на базе архитектурного шаблона **MVC (Model-View-Controller)**.

## 1. Клиентский уровень (Frontend / View)
Отвечает за визуальный интерфейс, неоновый дизайн в стиле Cyberpunk и интерактивный калькулятор характеристик.
* **Технологии:** HTML5, CSS3 (адаптивная верстка, CSS Grid/Flexbox), JavaScript (Vanilla JS / Fetch API).
* **Функционал:** Отображение каталогов, динамический подсчет очков характеристик в планировщике билдов без перезагрузки страницы (AJAX).

## 2. Серверный уровень (Backend / Controller)
Обрабатывает бизнес-логику приложения, проверяет валидность данных и связывает интерфейс с базой данных.
* **Технологии:** Node.js (с фреймворком Express) ИЛИ Python (с фреймворком FastAPI / Flask).
* **Функционал:** Авторизация геймеров (сессии/JWT), обработка CRUD-запросов (добавление отзывов, сохранение сборок персонажа), подсчет рейтинга популярности оружия.

## 3. Уровень данных (Database / Model)
Отвечает за надежное и структурированное хранение информации о Найт-Сити и профилях пользователей.
* **Технологии:** Реляционная СУБД **PostgreSQL** или **MySQL**.
* **Основные сущности (Таблицы):**
  * `Users` — данные геймеров (логин, хэш пароля, выбранная фракция).
  * `Weapons_Implants` — характеристики пушек и киберимплантов.
  * `Builds` — сохраненные конфигурации прокачки (связаны с ID пользователя).
  * `Comments` — отзывы и оценки квестов/билдов.
