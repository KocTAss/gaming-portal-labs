# Cyberpunk 2077 Wiki — gaming-portal-labs

Репозиторий для лабораторных и курсовой работы по дисциплине
**«Технологии разработки веб-приложений»**.

Тема проекта — вики-портал по игре **Cyberpunk 2077** (включая дополнение
**Phantom Liberty**): статьи о персонажах, фракциях, локациях, снаряжении и
квестах с поиском, регистрацией пользователей и комментариями.

## Команда

- Kosta

## О проекте

Портал-энциклопедия для игроков, которым нужно быстро найти информацию
по миру Найт-Сити.

**Планируемый функционал:**

- просмотр статей по категориям (персонажи, фракции, локации, оружие
  и импланты, квесты, Phantom Liberty);
- поиск по сайту;
- регистрация и вход в систему;
- личный профиль пользователя;
- комментарии к статьям.
